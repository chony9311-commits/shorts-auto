# 🎬 shorts-factory

쇼츠(9:16 · 1080×1920)를 **웹 UI에서 바로 만들어 뽑는** 로컬 자동 제작기.
영상 클립을 끌어다 놓고 → 줌·이동·원본 자막 지우기·상단 제목바·TTS·자막을 얹고 → MP4로 렌더한다.
내 컴퓨터(맥)에서만 돌아가고, 영상과 결과물은 `data/` · `output/` 폴더에만 남는다(Git에는 안 올라감).

---

## 1. 맥에서 3분 설치

```bash
# 1) ffmpeg (한 번만)
brew install ffmpeg

# 2) 내려받고 실행
git clone https://github.com/chony9311-commits/shorts-factory.git
cd shorts-factory
./run.sh
```

`./run.sh`가 파이썬 가상환경(`.venv`)과 의존성을 알아서 준비하고 서버를 띄운다.
브라우저에서 **http://localhost:8000** 을 열면 끝.

> 파이썬이 없다면: `brew install python` (3.10 이상)
> 포트를 바꾸려면: `PORT=9000 ./run.sh`
> 실행이 안 되면: `chmod +x run.sh`

### 자동 자막까지 쓰려면 (선택)

```bash
source .venv/bin/activate
pip install faster-whisper
```

자막을 굽지 않고 `.srt` 파일을 직접 올려도 된다.

## 2. 화면 구성

| 위치 | 하는 일 |
|---|---|
| 왼쪽 | 영상 클립 **드래그&드롭 업로드**, 순서 변경(↑↓), 컷 구간(시작·끝 초) 자르기, 음소거 |
| 가운데 | **9:16 미리보기 캔버스** — 확대(100~200%)·좌우/상하 이동 슬라이더, 마우스 드래그로 원본 자막·워터마크 가리기 |
| 오른쪽 위 | **썸네일·상단 제목바 프리셋 4종**, 제목 2줄, 금액/번호 배지, 출처 태그, 폰트 크기, 배경 딤, **썸네일 PNG 따로 뽑기** |
| 오른쪽 아래 | **원본음 / edge-tts TTS / 외부 MP3(타입캐스트·일레븐랩스)** 선택, 자동 자막, `.srt` 업로드 |
| 하단 바 | 총 길이(20~24초 권장 표시), 렌더 시작, 진행률, MP4 다운로드 |

미리보기 캔버스는 서버 FFmpeg와 **같은 크롭 계산식**을 쓰기 때문에, 보이는 그대로 렌더된다.


### 미리보기 캔버스 조작 (STEP 1)

캔버스 오른쪽 위 도구로 모드를 바꿉니다.

| 모드 | 단축키 | 동작 |
|---|---|---|
| ✋ 이동 (기본) | `V` | 캔버스를 **드래그**해 화면 위치 이동, `⌘`+휠(트랙패드는 **핀치**)로 확대 100~200% |
| ▭ 가림 | `M` | 드래그로 지울 영역 지정. 화면 중앙·좌우 여백선에 자석처럼 붙음 |
| ⬚ 선택 | `S` | 가림 박스 클릭 → 끌어서 이동, 모서리로 크기 조절, `Delete`로 삭제 |

그 밖의 단축키: `←` `→` 0.1초 이동(`Shift` 1초) · `,` `.` 이전/다음 컷 · `Space` 재생/정지 · `⌘Z` 되돌리기 · `⌘⇧Z` 다시 실행(가림 박스·컷 구간).
**안전영역** 체크 시 상단 220px·하단 420px(플랫폼 UI 구간)과 자막 위치를 점선으로 보여주고, 출처 태그·배지·제목바가 걸리면 경고합니다.

## 3. 기능

### 2가지 모드
- **쇼핑 쇼츠** — 한 플랫폼(쿠팡·네이버 등)의 3~5개 제품을 컷마다 하나씩. 각 컷 좌측상단에 **제품 번호 배지 1/3 …** 가 따라붙는다.
- **셀럽 쇼츠** — `@초몰입` 벤치마크. 번호 배지 대신 **출처/제품명 태그**가 우하단에 들어간다.

### 상단 제목바 프리셋 (버튼 한 번으로 교체)
| 프리셋 | 생김새 | 쓰는 곳 |
|---|---|---|
| **@초몰입형** | 노랑 줄 + 흰 줄 2단 굵은 제목바, 핵심 키워드에 형광펜 | 셀럽·핫템 후킹 |
| **꿀템담아형** | 검정 바 + 빨강 바탕 노랑 글씨 **금액 배지**(`80만 원 세이브`) | 손실회피형 쇼핑 |
| **마이픽형** | 파랑 컬러 배너 + **제품 번호 배지**(`1/3`, `TOP 3`) | 다제품 비교 |
| **심플 화이트/옐로우** | 흰 카드 + 라임 옐로우 형광펜, 고대비 | 깔끔한 정보형 |

제목줄에 `**키워드**` 처럼 별표 두 개로 감싸면 그 단어만 형광펜으로 강조된다.

### 줌 / 이동
`확대 100~200%` + `좌우·상하 이동` 슬라이더가 FFmpeg 크롭 창을 그대로 움직인다.
가로 영상(16:9)도 9:16으로 가운데가 잘려 들어가고, 확대하면 그만큼 밀어 넣는다.

### 원본 자막·워터마크 제거
미리보기 위를 **마우스로 드래그**하면 그 영역이 지워진다. 세 가지 방식:
- `boxblur` — 영역만 부드럽게 흐리게 (기본. 넓은 자막 띠에서 가장 자연스럽다)
- `delogo` — 주변 픽셀을 끌어와 뭉갠다 (작은 워터마크·로고에 적합)
- `drawbox + 한글 자막` — 검은 박스로 덮고 그 위에 한글 자막을 다시 쓴다

### 음성
- 기본 무료 **edge-tts** (한국어 보이스 3종, 속도 조절)
- **외부 MP3/WAV 업로드** — 타입캐스트·일레븐랩스에서 뽑은 파일을 그대로
- **faster-whisper**로 단어/문장 타임스탬프를 뽑아 `.ass` 자막 자동 싱크

### 썸네일
- 지금 클립의 **특정 초 프레임**을 캡처하거나, **직접 만든 이미지를 업로드**해서 바탕으로 쓴다
- 제목·배지·배경 딤을 얹은 **1080×1920 PNG**를 따로 저장 (`thumbnail.png`)
- 원하면 렌더 영상 **앞부분에 그 썸네일을 N초** 넣어 커버를 고정할 수 있다

## 5. API (코덱스가 확장할 때 참고)

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/api/state` | ffmpeg·폰트·프리셋·모드·보이스 |
| POST | `/api/clips` | 영상 클립 업로드(다중, `files`) |
| GET | `/api/clips/{id}/file` | 미리보기 스트리밍 |
| POST | `/api/audio` · `/api/tts` | 외부 오디오 업로드 · edge-tts 생성 |
| POST | `/api/images` | 커스텀 썸네일 이미지 업로드 |
| POST | `/api/transcribe` | 오디오 → ASS 자동 자막 |
| POST | `/api/subtitles` | `.srt/.ass/.vtt` 업로드 |
| POST | `/api/render` | 프로젝트 JSON → MP4 (백그라운드 잡) |
| GET | `/api/jobs/{id}` | 진행률·상태 |
| GET | `/api/download/{id}` | 완성 MP4 |
| POST | `/api/thumbnail` | 썸네일 PNG |

프로젝트 JSON 스키마는 `app/render.py` 맨 위 docstring에 정리되어 있다.

## 6. 자주 막히는 곳

| 증상 | 해결 |
|---|---|
| `ffmpeg를 찾을 수 없습니다` | `brew install ffmpeg` 후 `./run.sh` |
| 한글이 네모(□)로 나온다 | `fonts/` 폴더에 `NanumGothicBold.ttf` 넣기 (또는 `SHORTS_FONT=/경로/폰트.ttf`) |
| TTS가 실패한다 | 인터넷 연결 확인(edge-tts는 MS 서버 사용) |
| 자동 자막 버튼이 안 된다 | `pip install faster-whisper` 또는 `.srt` 업로드 |
| 렌더가 느리다 | `app/render.py`의 `-preset veryfast` 유지, 4K 원본은 미리 1080p로 줄이기 |
| iPhone HEVC 영상이 안 열린다 | 맥 `settings > 카메라 > 포맷`을 '높은 호환성'으로, 또는 ffmpeg로 mp4 변환 |

## 완전자동 쇼핑쇼츠 (상품 링크 → 9:16 MP4)

`[소스 수집 → 대본 → AI 성우 → 자동 컷편집 → 중앙 자막 → 렌더]` 를 링크만으로 한 번에 돌립니다.
웹 UI 상단의 **일괄 제작 (자동)** 탭, 또는 텔레그램 봇으로 사용합니다.

| 모듈 | 역할 |
|---|---|
| `app/scraper.py` | 쿠팡/네이버/일반 URL → 상품명·가격·특징 3~5줄·이미지/영상 URL. 막히면 `상품명 \| 특징 \| 가격` 직접 입력 |
| `app/source_fetcher.py` | 한/영/중 검색어 생성, yt-dlp 검색·다운로드(YouTube·Bilibili 자동), 샤오홍슈·도우인·틱톡은 검색 링크 + 내가 넣은 URL/로컬 클립. 1080×1920, 기본 115% 중앙 크롭 |
| `app/script_gen.py` | 20~25초 반말 대본(한 줄 8~13자), edge-tts(`SunHi` 여 / `InJoon` 남, +18%), 문장별 `silenceremove`, 실측 길이로 컷·자막 타임라인 생성 |
| `app/cutter.py` | 1.5~2.5초 컷 플래너(문장 경계 스냅), 소스 배정(반복·배속 없음, 부족하면 오류로 알림) |
| `app/subtitles.py` | `reels_center` 프리셋: 세로 55%, 볼드 고딕 72px, 흰색 + 외곽선 5 + 그림자 2, 한 번에 1줄 |
| `app/pipeline.py` | 위 단계를 이어 `render_video` 호출 |
| `app/batch_queue.py` | 순차 큐(동시 1개), 진행률, 직접 입력 재시도 |
| `app/bot.py` | 텔레그램 봇. 링크 → 큐 → 완료 보고 + MP4 전송 |

### 텔레그램 봇
```bash
cp .env.example .env      # TELEGRAM_BOT_TOKEN, TELEGRAM_ALLOWED_USER_IDS 입력
./run.sh                  # 웹 서버와 함께 봇이 뜹니다 (또는 python -m app.bot 으로 봇만)
```
허용 ID가 비어 있으면 모든 메시지를 거절하고 보낸 사람의 ID를 알려 줍니다. 그 값을 `TELEGRAM_ALLOWED_USER_IDS` 에 넣으세요.
명령어: `/voice female|male`, `/rate +18%`, `/status`. 봇 업로드 상한(50MB)을 넘으면 저장 경로만 알려 줍니다.

### 주의
- 쿠팡/네이버는 봇 접근을 막는 일이 많습니다. 그땐 직접 입력 폴백을 쓰세요.
- 내려받은 영상의 저작권·플랫폼 약관은 사용자 책임입니다. 원본 자막·워터마크는 115% 중앙 크롭으로 피하되 완전히 가려지진 않을 수 있습니다.
- 대본은 유료 API 없이 규칙(템플릿) 기반이라 문장 다양성에 한계가 있습니다. 생성 후 수동 편집 탭에서 다듬을 수 있습니다.
